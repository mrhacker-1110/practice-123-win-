{% if request.resolver_match.url_name == 'dashboard' %} {% if current_language == 'ru' %}

Главная — краткая сводка: сколько товара есть, что заканчивается и какие операции были недавно.

  1. Посмотри карточку «Мало на складе».
  2. Открой товар, чтобы проверить его остаток.
  3. Запиши поступление во вкладке «Поставки», а продажу — во вкладке «Продажи».
{% else %}

Home is a quick warehouse summary: stock on hand, items running low, and recent activity.

  1. Check “Low stock”.
  2. Open a product to review its quantity.
  3. Record deliveries in “Purchases” and sales in “Sales”.
{% endif %} {% elif request.resolver_match.url_name == 'products' or request.resolver_match.url_name == 'product_create' or request.resolver_match.url_name == 'product_update' or request.resolver_match.url_name == 'product_import' or request.resolver_match.url_name == 'product_delete' %} {% if current_language == 'ru' %}

Товары — список всего, чем вы торгуете. Артикул — ваш уникальный код товара, а «минимальный остаток» — порог, ниже которого запас считается низким.

  1. Добавь товар и укажи название, артикул, цену и минимальный остаток.
  2. Проверь предложенные камерой данные перед сохранением.
  3. Поступления и продажи сами меняют остаток; для пересчёта используй «Движения».
{% else %}

Products is your catalog. The product code is a unique label; “minimum stock” is the level at which the app marks an item as low.

  1. Add a product with a name, SKU, price, and minimum stock.
  2. Review any camera suggestions before saving.
  3. Purchases and sales update stock; use “Movements” for a stock count correction.
{% endif %} {% elif request.resolver_match.url_name == 'ai_consultant' %} {% if current_language == 'ru' %}

ИИ-консультант отвечает на вопросы о работе приложения и помогает обдумать складские задачи. Он не видит товары и цифры из вашей базы автоматически.

  1. Создай чат и задай вопрос.
  2. При необходимости прикрепи фото или файл.
  3. Проверь совет по своим данным; переписку можно найти и удалить в истории слева.
{% else %}

AI consultant answers questions about the app and helps think through warehouse tasks. It cannot automatically see products or figures in your database.

  1. Start a chat and ask a question.
  2. Attach a photo or file if useful.
  3. Check advice against your own records; find or delete chats in the history.
{% endif %} {% elif request.resolver_match.url_name == 'inventory_advisor' %} {% if current_language == 'ru' %}

Помощник по запасам сравнивает текущий остаток с продажами за последние 30 дней и примерно рассчитывает запас на 14 дней. Это подсказка, а не заказ поставщику.

  1. Проверь, правильно ли внесены продажи и остатки.
  2. Посмотри товары и предложенное количество.
  3. Учти срок доставки и сезон, затем оформи нужное поступление во вкладке «Поставки».
{% else %}

Stock assistant compares current stock with sales from the last 30 days and estimates a 14-day supply. It is a suggestion, not an order.

  1. Make sure sales and stock counts are up to date.
  2. Review the products and suggested quantities.
  3. Consider delivery time and season, then record the delivery in “Purchases”.
{% endif %} {% elif request.resolver_match.url_name == 'stock_movements' %} {% if current_language == 'ru' %}

Движения — журнал изменений количества товара: поступило, списано или пересчитано.

  1. Выбери товар и вид изменения.
  2. Для «Пересчёта» укажи фактическое количество на полке, а не разницу.
  3. Сохрани запись и проверь новый остаток в «Товарах».
{% else %}

Movements is the log of stock changes: received, removed, or counted.

  1. Choose a product and movement type.
  2. For “Adjustment”, enter the actual counted quantity, not the difference.
  3. Save and check the new stock in “Products”.
{% endif %} {% elif request.resolver_match.url_name == 'purchases' or request.resolver_match.url_name == 'purchase_create' %} {% if current_language == 'ru' %}

Поставки — учёт товара, который уже приехал от поставщика. После сохранения количество сразу прибавится к остатку.

  1. Выбери товар и поставщика.
  2. Укажи принятое количество и цену закупки.
  3. Сохрани только после фактического получения товара.
{% else %}

Purchases records goods that have arrived from a supplier. Saving a purchase immediately adds its quantity to stock.

  1. Choose the product and supplier.
  2. Enter the quantity received and purchase cost.
  3. Save after the goods have actually arrived.
{% endif %} {% elif request.resolver_match.url_name == 'suppliers' %} {% if current_language == 'ru' %}

Поставщики — контакты компаний и людей, у которых вы закупаете товары.

  1. Добавь название и удобный способ связи.
  2. Выбери поставщика при записи поступления.
  3. Сверяй контакт с документами поставки.
{% else %}

Suppliers stores contact details for the people and companies you buy from.

  1. Add a name and contact method.
  2. Select the supplier when recording a delivery.
  3. Match the contact to your purchase documents.
{% endif %} {% elif request.resolver_match.url_name == 'customers' %} {% if current_language == 'ru' %}

Покупатели — список клиентов, которых можно указать при оформлении продажи.

  1. Добавь имя или название компании.
  2. При продаже выбери клиента, если нужно его указать.
  3. Контактные данные используй для связи по заказу.
{% else %}

Customers stores clients you can select when recording a sale.

  1. Add a name or company.
  2. Select the customer when recording a sale if needed.
  3. Use the contact details to follow up about the order.
{% endif %} {% elif request.resolver_match.url_name == 'sales_report' or request.resolver_match.url_name == 'sale_create' %} {% if current_language == 'ru' %}

Продажи — регистрация проданных товаров и сводка выручки. При сохранении продажи остаток уменьшится; сумма считается по цене товара в карточке.

  1. Для новой продажи нажми «Записать продажу».
  2. Выбери товар, количество и при необходимости покупателя.
  3. Для отчёта выбери период.
{% else %}

Sales records sold items and summarizes revenue. Saving a sale reduces stock; the total uses the price in the product record.

  1. Choose “Record sale” to add a sale.
  2. Select the product, quantity, and customer if needed.
  3. Choose a period for the report.
{% endif %} {% elif request.resolver_match.url_name == 'profile' %} {% if current_language == 'ru' %}

Профиль — ваши контактные данные и сведения об аккаунте.

  1. Проверь имя и телефон.
  2. Измени нужные поля.
  3. Нажми «Сохранить» внизу формы.
{% else %}

Profile contains your contact details and account information.

  1. Review your name and phone.
  2. Update the fields you need.
  3. Click “Save” at the bottom of the form.
{% endif %} {% elif request.resolver_match.url_name == 'plans' or request.resolver_match.url_name == 'plan_detail' %} {% if current_language == 'ru' %}

Тарифы показывают, какие возможности и ограничения доступны в каждом варианте.

  1. Сравни лимит товаров и нужные функции.
  2. Открой «Подробнее», чтобы прочитать условия.
  3. Выбирай платный вариант только если он подходит по цене и возможностям.
{% else %}

Plans show the features and limits included in each option.

  1. Compare product limits and the features you need.
  2. Open “Details” to read the plan information.
  3. Choose a paid option only if its price and features fit your needs.
